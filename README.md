# 4-Way VIPT Instruction Cache (SystemVerilog)

A 16 KB, 4-way, **virtually-indexed physically-tagged**, **non-blocking** instruction cache for a RISC-V front end.

- **3-stage pipeline**: index the tag SRAM with the VA → ITLB + 4-way tag compare → read only the hit way.
- **VIPT without aliasing**: the 4 KB way size equals the page size, so index bits come from the page offset.
- **ITLB**: 8-entry fully associative, with a page-table-walker port and page-fault reporting.
- **MSHRs**: 2 entries × 4 targets. Hit-under-miss, secondary-miss merging, critical-word forwarding from the fill buffer.
- **Tree pseudo-LRU** replacement (3 bits/set), invalid way first.
- **SRAM macro models**: 1RW, 1-cycle read. Valid bits in flops for 1-cycle `fence.i`.
- Out-of-order responses tagged with a request id. Hit/miss/merge/walk counters.

Full design notes: [docs/DESIGN.md](docs/DESIGN.md)

## Layout
```
rtl/      icache_pkg, sram_1rw, icache_tag_array, icache_data_array,
          plru_tree, itlb, icache_mshr, icache_top
tb/       one self-checking testbench per module
tests/    .txt stimulus + expected values (generated by scripts/gen_tests.py)
docs/     DESIGN.md
```

## Run
```
make              # all testbenches, Verilator
make SIM=icarus   # same with Icarus Verilog
make top          # just the full cache
make lint         # verilator -Wall on the RTL
make vectors SEED=7   # new random vectors
```

Sample result:
```
fetches 8662 | hits 8067 | primary misses 163 | merged misses 430 | itlb walks 28 | faults 2
hit rate 93.13% | 0.85 fetch/cycle
PASS tb_icache_top
```
